الدبل للخدمات - حزمة التثبيت PWA

هذه الحزمة تضيف قابلية التثبيت والعمل دون اتصال لملف الواجهة الحالي دون تغيير تصميمه الظاهر.

محتويات جذر المستودع المطلوبة:
- index.html
- manifest.webmanifest
- service-worker.js
- مجلد icons وفيه icon-192.png و icon-512.png

مهم:
- يجب نشر الملفات على استضافة HTTPS مثل GitHub Pages.
- هذه الحزمة تجعل الواجهة الحالية قابلة للتثبيت؛ لا تضيف وحدها ربط Supabase أو تحويل الطلبات التجريبية المحلية إلى طلبات فعلية.
- عند نشر إصدار جديد من الملفات، يتولى Service Worker تنزيل النسخة الجديدة واستبدال ملفات التخزين المؤقت.
